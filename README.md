NeerThuli-Download# Neer Thuli Admin & Employee App v1.0.0

🚀 Initial Portfolio Release

This is the first public release of the **Neer Thuli Water Delivery Management System**, built using **Kotlin**, **Jetpack Compose**, **MVVM**, **Firebase**, and **Material 3**.

✨ Admin App Features

- Modern dashboard with revenue overview
- Customer management
* Inventory management with product categories and variants
* Stock management (Add, Update, Edit, Delete)
* Sales and profit analytics
* Revenue and expense charts
* Shop-wise inventory tracking
* Dark Mode & Light Mode support
* Responsive Material 3 UI

### 👨‍💼 Employee App Features

* Record daily sales
* Empty can collection tracking
* Available stock overview
* Sales history
* Dark Mode & Light Mode support
* Optimized user interface for field employees

### 🛠 Tech Stack

* Kotlin
* Jetpack Compose
* MVVM Architecture
* Firebase Authentication
* Cloud Firestore
* Material 3
* Coroutines
* StateFlow
* Navigation Compose

### 📈 Highlights

* Clean and modern SaaS-inspired UI
* Real-time cloud synchronization
* Inventory and sales management
* Analytics dashboard
* Optimized performance
* Responsive design for phones and tablets

### ⚠️ Notes

This application is a portfolio project created to demonstrate modern Android development practices and architecture. New features, UI improvements, and performance optimizations will continue to be added in future releases.
